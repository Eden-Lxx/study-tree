# study-tree · 学习树（项目功能备忘）

> 一句话：一个「能力 / 知识点」成长树单页应用，自带多用户、蓝图分享、好友和笔记。

## 一、这是什么

- 把自己要学的东西画成一棵「学习树」：**父级能力**（大方向）下面挂**知识点**（子节点）。
- 每个知识点有「时间成本」，点亮它消耗「科技点」；父级成本 = 所有子节点之和。
- 支持周常任务每周重置、前置依赖、等级经验，鼓励持续学习。

## 二、技术架构（零依赖）

| 文件 | 作用 |
|---|---|
| `server.js` | 后端服务，只用 Node 内置模块，`node server.js` 即跑 |
| `index.html` | 前端单页应用（画布、市场、资料等全部在这里） |
| `package.json` | 项目元信息 + 启动脚本 |
| `data/` | 全部数据（账号、学习树、笔记、蓝图、好友） |
| `Dockerfile` / `docker-compose.yml` | 容器化部署 |
| `启动.bat` | Windows 一键启动本地服务（0.0.0.0:5173） |
| `公网临时访问.bat` | 用 cloudflared 开临时公网隧道分享 |
| `安全上线清单.md` | 搬到公网服务器前的安全自查手册 |
| `remind.md` | 本文件（功能备忘） |

## 三、功能清单

### 账号与安全
- 注册 / 登录 / 登出，密码 scrypt 加盐哈希，httpOnly Cookie 会话
- 昵称、头像（可裁剪上传）
- 登录限速（防爆破）、静态文件白名单、CSP 等安全头

### 学习树（核心）
- 三大基础分类（艺术 / 运动 / 学习），可增删分类
- 父级能力固定在左栏，画布可**拖拽 / 缩放**
- 知识点可点亮（消耗科技点）、可设前置依赖
- 父级成本 = 子节点之和，连线展示父子/前置关系
- 周常任务每周自动重置；等级经验（点亮得经验）

### 笔记
- 支持 md / pdf / txt / doc / docx / ppt / pptx / 图片
- md 可**在线编辑**，pdf/图片在线预览，Office 文档需下载后用本机 Word/WPS/PowerPoint 打开
- 笔记挂在具体节点下，按账号隔离

### 蓝图市场
- 把某个父级「发布成蓝图」，别人可一键导入
- 市场分类：运动 / 学习 / 艺术 / 其他 + **好友蓝图**筛选
- 蓝图可见性：**公开 / 仅好友 / 私人**
- 蓝图评分（标题/说明/节点/节点笔记/附件六维，0–100）
- 我的蓝图库：可改标题、说明、分类、可见性，或「用当前学习树更新内容」

### 社交
- 好友：**申请 → 同意** 制
- 访客模式：只读查看好友的学习树
- 等级、个人资料卡

### 管理与反馈
- 管理员后台：查看/搜索账号、改角色、看任意人的学习树和蓝图
- 意见反馈：用户提交，管理员回复

## 四、快速启动

```bash
# 方式一：Windows 直接双击「启动.bat」
# 方式二：命令行
node server.js
# 然后浏览器打开 http://127.0.0.1:5173
```

首次注册的账号会自动成为管理员。数据都在 `data/` 目录，按账号隔离。

## 五、常用环境变量

| 变量 | 作用 |
|---|---|
| `PORT` / `HOST` | 监听端口 / 地址（默认 5173 / 0.0.0.0） |
| `TT_DATA_DIR` | 数据目录（默认 `./data`） |
| `TT_PUBLIC=1` | 公网严格模式（加 HSTS / Secure Cookie） |
| `TT_CLOSE_REGISTER=1` | 关闭自助注册 |
| `BP_MIN_SCORE` | 蓝图最低上架评分（默认 0 不拦截） |
| `NO_OPEN=1` | 启动后不自动开浏览器 |
